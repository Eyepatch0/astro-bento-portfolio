# Portfolio

This is my personal portfolio website, built using Astro and based on the Bento theme. I customized it to reflect my style and showcase my projects effectively.

## Features

- • Clean and modern design
- • Fully responsive layout
- • Custom sections for projects, skills, and contact
- • Smooth animations and transitions

## Technical Details

The portfolio was built using:

- • **Astro** for the framework
- • **unocss** for utility-first styling
- • **motion** for animations and smooth transitions
- • **d3** for data visualization elements

## Implementation

This project is a customized fork of the [Bento Astro Portfolio](https://github.com/Ladvace/astro-bento-portfolio). I made several modifications to the design, layout, and content to better suit my personal branding and showcase my work.
